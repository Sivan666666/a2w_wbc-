# 25K基线之后的优化方案草案

状态：仅供批准，未实施、未启动。用户目前只授权迁移25K基线。
目标优先改善扩展域EE姿态，同时守住原生EE位置、XY/yaw和失败reset。
不把世界模型预测改善直接当作策略跟踪改善。

## 先补齐25K证据

现有joint2退步分析比较10K和30K，不能直接归因到25K。
建议先在相同已有轨迹上离线分析25K的1至32步joint2/joint4误差、
真实状态单步与自回归差距、逐步误差相关性和动作响应；模型保持冻结，新增采样为0。
已有物理有限差分在长时域对扰动幅度敏感，且缺少受扰动关节轨迹，
不能用它作为精确关节Jacobian的监督真值。

15ms延迟组并非全部退步；该延迟已进入context，前一控制动作也已输入。
控制周期20ms包含4个5ms子步，而配置延迟最大4子步。
不能未经核对就认定缺少更多动作历史是根因；先核实子步延迟buffer时序和
状态、动作、目标的时间对齐。接触状态、观测噪声与长时域误差传播须分别讨论。

## 下一步只试一个可归因的改动

若25K仍表现为单步近似正常、长时域关节漂移，可优先提出“机械臂q与qd时间一致性”
的单因素WM对照，而不是重复已失败的姿态辅助损失扫参、扩大窗口或同时改网络。
先在已有真实轨迹上测出控制周期积分近似本身的误差，不能把终点速度乘dt
当作精确关节位移；若近似偏差过大，这一候选应放弃而非强加约束。

可供审批的初步预算是两个离线WM组各500更新，合计1000更新，最多4小时；
两组同25K初始化、同数据/采样顺序、同Adam处理与归一化，Actor/Critic冻结。
仅在前置诊断通过后确定约束形式和固定系数，不做自动扫参或追加预算。
这是建议预算，不是已授权预算。

已经多次分析过的旧封存测试集现在只能当诊断集，不能再声称盲测。
若要作新的模型选型/验收，应先固定方案并获得独立数据或未查看数据的使用授权；
任何新增仿真采集都需要另行批准与计数。

## 策略训练仍需独立批准

仅在WM预测与动作响应证据支持后，再决定是否做独立策略warm-start。
需明确恢复哪些权重/优化器、replay重建、预热、LR日程和新增物理/想象预算。
现有25K基线不可覆盖，PS1旧run不可重启，A100只允许物理GPU7。
暂不为策略训练填入默认轮数，也不自动把原40K余量迁为新预算。

最终仍须以固定检查点扩展域三种子×64env×200秒的独立物理评测验收。
原域只作补充；报告姿态、原生EE、XY/yaw、失败reset和全部成本，
不把单一指标降低、CPU接口通过或换A100带来的吞吐提升称为整体算法改进。
